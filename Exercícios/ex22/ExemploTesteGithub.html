Dicas de git e github

  • Use git init para inicializar um repositório local
  • Use git add . para começar a adicionar todos os arquivos
  • Use git commit -m "msg" para fazer um comentário com uma mensagem
  • Use git push origin main para enviar as alterações para o GitHub
  • Use git pull origin main para puxar do GitHub para o repositório local
  • Use git clone "url_do_repositório" para clonar um repositório do GitHub
  • Use git checkout -b nome_da_nova_branch para criar uma nova branch
  • Use git checkout nome_da_branch para mudar de branch
  • Use git branch para ver as branches existentes
  • Use git merge nome_da_branch para mesclar uma branch com a atual
  • Use git status para ver o status do repositório
  • Use git log para ver o histórico de commits
  • Use git remote remove origin para remover o repositório remoto
  • Use git reset --hard HEAD~1 para reverter o último commit
  • Use git fetch para atualizar os dados do repositório remoto
  • Use git exit para sair do git
